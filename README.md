# 🛡️ ABlacklist

### Меньше шума — больше нужных объявлений.

**ABlacklist** — браузерное расширение для Avito, которое помогает управлять выдачей прямо во время просмотра. Скрывайте ненужные объявления и блокируйте продавцов одним нажатием.

Без регистрации, сервера и передачи чёрного списка третьим лицам. Все данные остаются в вашем браузере. 🔒

## ✨ Возможности

- **× Скрытие объявления** — уберите конкретную карточку и сохраните выбор для следующих посещений.
- **⊘ Блокировка продавца** — скрывайте его объявления по идентификатору или ссылке профиля.
- **↩️ Отмена действия** — верните карточки через уведомление.
- **🔎 Менеджер списков** — поиск, причины блокировки, разблокировка и восстановление объявлений.
- **🧹 Стоп-фразы** — фильтруйте объявления по словам в заголовке и тексте карточки.
- **📦 Импорт и экспорт** — сохраняйте резервные копии и переносите списки в JSON.
- **⚙️ Настройки без перезагрузки** — управляйте фильтрацией, кнопками и анимациями.
- **🌙 Тёмный интерфейс** — компактный popup и удобная страница управления.

## 🖱️ Как это работает

1. Откройте выдачу Avito.
2. Наведите курсор на карточку объявления.
3. Нажмите **×**, чтобы скрыть объявление, или **⊘**, чтобы заблокировать продавца.
4. Продолжайте просмотр — новые карточки тоже проходят проверку.

На сенсорных устройствах кнопки остаются видимыми. Блокировка привязана к ID или адресу профиля, поэтому продавцы с одинаковыми именами не считаются одним человеком.

## 🚀 Установка

Расширение готово к установке — **npm и сборка не нужны**.

1. Скачайте проект и распакуйте архив.
2. Откройте страницу расширений:
   - **Chrome:** `chrome://extensions`
   - **Edge:** `edge://extensions`
   - **Яндекс Браузер:** `browser://extensions`
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку `ABlacklist`, содержащую `manifest.json`.
6. Откройте или обновите вкладку Avito.

## 🔐 Приватность

- Списки и настройки хранятся в `chrome.storage.local`.
- Нет аналитики, трекеров и внешних CDN.
- Чёрный список не отправляется на сервер.
- Доступ расширения ограничен страницами Avito.
- Если продавца нельзя определить по карточке, расширение может загрузить публичную страницу объявления. Такие запросы используют очередь, кеш и таймаут.

> 💾 Перед удалением расширения сохраните экспорт: браузер удалит его локальные данные вместе с расширением.

## 🧩 Технологии

`Manifest V3` · `JavaScript` · `HTML` · `CSS` · `MutationObserver` · `IntersectionObserver` · `chrome.storage.local`

Модульная архитектура разделяет работу с DOM, определение продавцов, хранение данных, фильтрацию и интерфейс.

## ✅ Статус проекта

Рабочий MVP. Автоматические проверки в Microsoft Edge охватывают сохранение списков, Undo, динамические карточки, настройки, импорт/экспорт и подгрузку тестовой ленты.

На настоящем Avito проверены появление кнопок и скрытие объявления. Полная проверка всех вариантов бесконечной прокрутки и виртуализации Avito пока не завершена. Яндекс Браузер отдельно не тестировался.
